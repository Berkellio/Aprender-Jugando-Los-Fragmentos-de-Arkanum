# Arkanum

> Sistema pedagógico que combina la narrativa y reglas de D&D 5e con aprendizajes prácticos en STEAM (Diseño 3D, Electrónica con Arduino y Programación con Python).

## 📌 Sobre el Proyecto

**Arkanum** es un marco educativo diseñado para docentes —tengan o no experiencia previa en juegos de rol (D&D)— que busca transformar el error técnico en una herramienta pedagógica bajo la premisa: *"El error es información, no castigo"*. 

A través de la resolución de problemas reales (código con errores de sintaxis, circuitos mal conectados o modelos 3D con fallos de estructura), los estudiantes avanzan en la narrativa del juego analizando e identificando fallos.

## 🎯 Público Objetivo

- **Docentes sin experiencia en D&D:** Encuentran guías paso a paso para dirigir sesiones sin necesidad de conocer todas las reglas complejas del juego.
- **Docentes con experiencia en D&D:** Pueden integrar rápidamente dinámicas de rol clásicas con retos técnicos reales de ciencias y tecnología.

## 📂 Estructura Planificada del Repositorio

El proyecto se dividirá en los siguientes componentes (en desarrollo):

- `/manuales/`: Guías de introducción a D&D para el jugador y el Dungeon Master.
- `/guia-docente/`: Manual específico de Arkanum para implementación rápida en el aula.
- `/bestiario/`: Compilación de criaturas adaptadas de distintas aventuras para los encuentros.
- `/retos-steam/`:
  - `/3d/`: Modelos 3D con fallos intencionados para corrección.
  - `/electronica/`: Circuitos y sketches de Arduino para depuración física.
  - `/programacion/`: Scripts en Python con errores lógicos o de sintaxis.
